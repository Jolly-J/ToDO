# ToDO 任务管理器 · 产品展示主页 (Landing Page)

本目录为 **「ToDO 任务管理器」** 的开源官方展示主页与产品落地页。融合了 Apple 与 Notion 级的高质感视觉设计系统、全流程拟真交互沙盒以及团队协同最佳实践。

---

## 🌟 页面亮点

1. **统一全景导航与苹果微光质感**：
   - 顶部毛玻璃固定导航栏，一键直达核心特性、交互剧场、协同约定、多角色视角与 GitHub 仓库；
   - 采用 Apple Developer 级交互式星芒微光网格背景（Canvas 实时雷达透镜与平滑缓动）；
   - 旗舰级 MacBook 视口界面展台，直观感受沉浸式产品体验。

2. **四大核心能力 Bento 矩阵**：
   - 多级任务拆解（公司级、项目级、团队级、小组级一眼穿透）；
   - 钉钉原生全流程搞定（免登鉴权、工作通知、09:30 定点催办）；
   - 双端联动随办随查（PC 统筹大盘，手机端随时响应）；
   - 极简开箱专注交付（单文件 SQLite，零冗余配置与隐形开销）。

3. **沉浸式交互剧场 (The Flow Theater)**：
   - 左侧时间线平滑跟随指示圆点；
   - 右侧 1:1 macOS 交互沙盒（工作台大盘、三栏 WBS 拆解实时点击勾选算分、个人 4 维关系自动轮播切换、权限隔离与调岗安全交接拦截）。

4. **团队高效协同的 6 个默契约定 (Bento Grid Motion 展台)**：
   - 实践 01：大任务 WBS 细化拆解，颗粒度 1~3 天（激光光刃切割动效）；
   - 实践 02：坚守单责任人制 Single Owner（头像动态聚焦动效）；
   - 实践 03：钉钉 09:30 定时群提醒（垂直无缝滚动通知流动效）；
   - 实践 04：敏感业务权限隔离（开关切换与毛玻璃锁定层动效）；
   - 实践 05：离队安全交接拦截（盾牌防护与资产批量平移流转）；
   - 实践 06：日历全景负荷平衡（横跨 3 列全景时间线调平平移动效）。

5. **三层角色协同全景画廊**：
   - 管理者视角（全局看板、团队管理、进度穿透、风险提醒）；
   - 负责人视角（任务拆解、一键指派、实时跟进、协作同步）；

6. **钉钉原生生态深度打通 & 社区共创倡议**：
   - 免登与组织同步、待办中心打通、工作通知 ActionCard、群聊机器人定点催办、消息审计与撤回；
   - 热忱招募社区开发者共创**企业微信（WeCom）**与**飞书（Lark）**生态适配驱动插件。

7. **100% 独立自包含与零外部依赖**：
   - 无需 npm 构建，内置响应式 CSS 与 Vanilla JS，秒级即开即跑；
   - 完美适配 PC 浏览器、移动端与各类企业协同平台端内 WebView。

## 🚀 本地预览与部署方式

### 方式一：本地直接打开
直接双击本目录下的 `index.html`，即可在 Chrome / Safari / Edge 等现代浏览器中流畅体验全部动效与交互。

或使用任意本地静态服务器：
```bash
# 进入 showcase 目录
cd showcase

# 使用 Python 启动快速预览服务器
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080 即可
```

### 方式二：部署为 GitHub Pages
1. 在 GitHub 仓库设置中（Settings -> Pages）；
2. Source 选择 `Deploy from a branch`；
3. 分支选择 `main`，目录选择 `/showcase`；
4. 保存后即可获得专属项目官网域名！

### 方式三：作为钉钉 ActionCard 承载页全员推送
1. 将 `showcase/index.html` 与 `showcase/assets/` 作为承载落地页托管在服务器静态路径下；
2. 登录 ToDO 管理后台 -> 点击【钉钉推送】；
3. 选择 `ActionCard` 消息，配置宣传文案并关联本展示页链接；
4. 点击全员推送，团队成员即可收到精美的协同指南卡片！
