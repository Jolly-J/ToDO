**ToDO 任务管理器**是一套专为团队日常协作与闭环交付打造的高效任务中枢系统。我们拒绝复杂的流程说教与技术自嗨，直接扎根于团队日常工作的真实切片：从晨会排期大盘统揽、多级目标 WBS 细化拆解，到智能定时催办、敏感情境权限隔离与离岗无缝交接，帮助团队沉淀“权责清晰、节奏可预期、事事有回音”的交付默契。

## 我们的协同理念

好的数字化工具不仅规范进度，更沉淀组织的交付默契与信任。ToDO 的核心设计围绕以下 5 大管理实践构建：

1. **坚持单人负责制（Single Owner）**：
   一件任务多个人负责往往等于无人负责。ToDO 倡导每一项任务必须有且仅有唯一的直接责任人（Owner），对交付质量端到端闭环；其他跨部门协助人员归入参与人，权责对等不推诿。
2. **任务粒度控制在 1~3 天（WBS 科学拆解）**：
   执行周期超过 1 周的任务极易沦为拖延黑洞。利用 WBS 将庞大战略目标层层化整为零，细化拆解为可独立验收的最小行动单元。
3. **系统节拍自驱动（智能定时自动催办）**：
   按团队工作节拍定点汇总团队临期、超期任务，群机器人精准 @责任人。用系统客观的规律节拍驱动自我管理，彻底解放管理人员肉身催单的尴尬与内耗。
4. **日常执行 4 维清爽流（聚焦当下深度工作）**：
   以“分派给我、由我创建、参与协作、关注任务”四维结构清晰收拢待办。团队成员上班不用在零散的聊天记录里到处翻找任务，轻重缓急一目了然，今日事今日毕。
5. **空间治理与资产零断档（权限隔离与离队交接）**：
   绩效考核、财务等敏感情境开启【仅见相关】，非名下任务物理级隔绝，各司其职；成员调岗或离职移出团队时触发安全拦截，名下任务一键批量交接平移，组织数字资产永不脱节。

## 技术架构

### 前端技术栈 (Client)
- **核心基础**：React 19 + TypeScript 5.9 + Vite 8
- **排版与组件库**：Tailwind CSS 4 + shadcn/Radix UI + Ant Design + Lucide Icons
- **状态流转**：Zustand
- **富文本能力**：TipTap 编辑器引擎

### 后端技术栈 (Server)
- **运行环境**：Node.js + Express 5 (CommonJS 模块规范)
- **数据持久化**：SQLite (`better-sqlite3` 高性能同步驱动)
- **数据库版本控制**：Knex 增量结构迁移 (Migrations)
- **任务调度引擎**：node-cron
- **外部能力集成**：钉钉开放平台 OpenAPI

### 架构优势
- **极简自托管**：基于 SQLite 单文件存储与轻量 Node 运行时，无需额外配置臃肿的数据库集群或复杂中间件。
- **数据资产安全**：支持 100% 本地或私有云部署，所有任务、文档与讨论记录自主掌控，杜绝云端泄密风险。
- **秒级部署冷启动**：极低的内存占用与算力消耗，开箱即用。

## 快速上手（本地开发调试）

### 1. 环境准备
- Node.js >= 18.0.0
- npm >= 9.0.0

### 2. 获取代码与依赖安装

```bash
# 克隆代码仓库
git clone https://github.com/Jolly-J/ToDO.git
cd ToDO

# 安装根目录及前后端依赖
npm install
npm --prefix client install
npm --prefix server install
```

### 3. 配置环境变量

从示例模板复制前后端配置：

```bash
# 服务端配置
cp server/.env.example server/.env

# 前端配置
cp client/.env.example client/.env
```

按需修改 `server/.env`（详见文件内部注释）：
- `JWT_SECRET`：设置自定义随机密钥。
- `INITIAL_SUPER_ADMIN_IDS`：设置系统初始管理员用户 ID（以英文逗号分隔）。
- 钉钉参数（如需联调企业免登与机器人功能按需配置）。

### 4. 启动开发服务

```bash
npm run dev
```

服务启动后访问：
- 前端交互界面：`http://localhost:8821`
- 后端 API 服务：`http://localhost:8344`
